# Module 4 – Genome Assembly

## Module Overview

Whole genome assembly reconstructs the genome of an organism by joining overlapping sequencing reads into longer contiguous sequences called **contigs**. Rather than analyzing millions of individual sequencing reads, genome assembly produces a draft genome that can be used for downstream analyses such as genome quality assessment, sequence typing, antimicrobial resistance gene detection, and comparative genomics.

In this module, you will assemble the trimmed paired-end sequencing reads using **SPAdes**, one of the most widely used assemblers for bacterial genomes. By the end of this module, you will have generated a draft genome assembly that will serve as the foundation for all subsequent analyses.

## Background

Genome assembly reconstructs longer DNA sequences by identifying overlaps among sequencing reads. Because bacterial genomes are relatively small and typically contain a single circular chromosome, **de novo assembly** is often the preferred approach when no reference genome is available or when an unbiased reconstruction is desired.

SPAdes is specifically designed for assembling bacterial genomes from Illumina sequencing data. It automatically performs multiple assembly steps, including error correction and graph-based assembly, to produce high-quality draft genomes.

The primary output of SPAdes is a FASTA file containing assembled contigs, which will be used throughout the remainder of this workshop.

## Commands

### Step 1. Create an output directory

``` bash
mkdir -p results/assembly
```

------------------------------------------------------------------------

### Step 2. Run SPAdes

``` bash
spades.py \
-1 results/trimmed_reads/10-0213-20-0000_S42_R1_P.fastq.gz \
-2 results/trimmed_reads/10-0213-20-0000_S42_R2_P.fastq.gz \
-o results/assembly/10-0213-20-0000_S42 \
-t 8
```

> **Note:** Genome assembly is computationally intensive and may take several minutes depending on your computer and dataset.

## Understanding the Main Output Files

Although SPAdes generates many files, only a few are routinely used in bacterial genome analysis.

| File | Description |
|----------------|--------------------------------------------------------|
| `contigs.fasta` | Primary draft genome assembly consisting of contiguous sequences. |
| `scaffolds.fasta` | Scaffolded genome assembly where contigs may be linked using paired-end information. |
| `spades.log` | Complete log of the assembly process. |
| `params.txt` | Parameters used during assembly. |
| `warnings.log` | Any warnings generated during assembly. |

For most downstream analyses in this workshop, **`contigs.fasta`** will be used.
